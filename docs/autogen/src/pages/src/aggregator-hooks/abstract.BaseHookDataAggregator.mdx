# BaseHookDataAggregator

[Git Source](https://github.com/Uniswap/v4-hooks-internal/blob/d2a38d0852d124855be2202d8846e0259e3cfe28/src/aggregator-hooks/BaseHookDataAggregator.sol)

**Inherits:** [BaseAggregatorHook](/src/aggregator-hooks/abstract.BaseAggregatorHook)

**Title:** BaseHookDataAggregator

Variant of [BaseAggregatorHook](/src/aggregator-hooks/abstract.BaseAggregatorHook) for aggregator hooks whose swap behaviour depends on the per-swap
`hookData` (e.g. an encoded order, intent, or signature). It forwards `hookData` into a hookData-aware
`_conductSwap`, so implementations read it straight from calldata — no storage stash, and no change to
the routing `quote` interface.

<i>

This contract only overrides settlement so it can thread `hookData` through to a hookData-aware
`_conductSwap`; the shared delta/protocol-fee accounting is reused from `BaseAggregatorHook._innerBeforeSwap`,
so there is no duplicated logic to keep in sync with the base.
Hooks that do not need `hookData` should continue to extend [BaseAggregatorHook](/src/aggregator-hooks/abstract.BaseAggregatorHook) directly so they remain
completely unaffected by this variant.

</i>

<a id="_conductswap-currency-currency-swapparams-poolid"></a>

### _conductSwap

Abstract function for contracts to implement conducting the swap on the aggregated liquidity source

<i>

Sealed: hooks on this base implement the hookData-aware overload below. This overload is never reached
because `_beforeSwap` routes through `_internalSettleWithHookData`.

</i>

```solidity
function _conductSwap(Currency, Currency, SwapParams calldata, PoolId)
        internal
        override
        returns (uint256, uint256, bool);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _ | `Currency` | The currency to be settled on the V4 PoolManager (swapper's output currency) |
| _ | `Currency` | The currency to be taken from the V4 PoolManager (swapper's input currency) |
| _ | `SwapParams` | The swap parameters |
| _ | `PoolId` | The V4 Pool ID |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `uint256` | The amount of the currency being settled (swapper's output amount) |
| &lt;none&gt; | `uint256` | The amount of the currency being taken (swapper's input amount) |
| &lt;none&gt; | `bool` | Whether the swap has been settled inside of the _conductSwap function |

<a id="_rawquote-bool-int256-poolid"></a>

### _rawQuote

Returns the raw quote from the underlying liquidity source without protocol fees

<i>

Router-style quoting (no hookData) cannot resolve a per-swap order, so it is unsupported. Use
[quoteWithHookData](#quotewithhookdata) instead, supplying the order as hookData.

</i>

```solidity
function _rawQuote(bool, int256, PoolId) internal virtual override returns (uint256);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _ | `bool` | Whether the swap is from token0 to token1 |
| _ | `int256` | The amount specified (negative for exact-in, positive for exact-out) |
| _ | `PoolId` | The pool ID |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `uint256` | The raw unspecified amount before protocol fee adjustment |

## Errors

### HookDataRequired

Thrown if the hookData-less `_conductSwap` overload is somehow reached. Hooks built on this base
only implement the hookData-aware overload.

```solidity
error HookDataRequired();
```

