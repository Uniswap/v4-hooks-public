# TempoExchangeAggregator

[Git Source](https://github.com/Uniswap/v4-hooks-public/blob/3d5b2620fe2b9ba7f01645160e1b841cf585c425/src/aggregator-hooks/implementations/TempoExchange/TempoExchangeAggregator.sol)

**Inherits:** [BaseAggregatorHook](/src/aggregator-hooks/abstract.BaseAggregatorHook)

**Title:** TempoExchangeAggregator

Singleton Uniswap V4 hook that aggregates liquidity from Tempo's enshrined stablecoin DEX

<i>

Supports multiple pools and both exact-input and exact-output swaps

</i>

<i>

Tempo uses uint128 for amounts; this contract handles the conversion from uint256

</i>
