**Title:** VolatilePairHook

Dynamic fee hook for volatile pairs (v2 skew + backrun algorithm); UUPS proxy is the
registered v4 hook. The fee math lives in VolatileFeeCalculation; this contract loads
state, calls it, and stores.

<i>

A swapper buying token0 (zeroForOne false, price goes up) pays the ask fee; a swapper selling
token0 (zeroForOne true, price goes down) pays the bid fee. All fees are LP fees and do not take
the pool's protocolFee into account; when it is turned on, v4 adds it on top of the returned fee.

</i>

**Note:**

- **security-contact:** security@uniswap.org

## Constants

### maxTempFeeBlockGap

Most blocks after the previous block open at which a block's temp fee still applies.

<i>

Immutable so it is set per chain and changes only through an upgrade

</i>

```solidity
uint256 public immutable maxTempFeeBlockGap;
```

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `uint256` | The max block gap |

<a id="_loadtopofblockstate-poolid"></a>

### _loadTopOfBlockState

Loads a pool's config and state, advancing the state to this block's skew and temp fee
in memory without writing.

<i>

New block: steps the permanent skew and prices the backrun charge from the price impact
since the previous open, then caches the new open. The backrun charge is dropped when the
previous open was more than `maxTempFeeBlockGap` blocks ago. Same block: returns the stored
values unchanged.

</i>

```solidity
function _loadTopOfBlockState(PoolId _poolId)
        private
        view
        returns (VolatileFeeState memory, VolatileFeeConfig memory, uint160, bool);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _poolId | `PoolId` | Pool id |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `VolatileFeeState` | Fee state, advanced on a new block |
| &lt;none&gt; | `VolatileFeeConfig` | Fee config |
| &lt;none&gt; | `uint160` | Pool's current sqrt price |
| &lt;none&gt; | `bool` | True on the first swap of a new block, or right after a config reset |
