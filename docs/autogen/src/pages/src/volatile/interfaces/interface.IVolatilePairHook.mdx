### initializePool

Initializes a pool on the PoolManager and sets its fee config.

```solidity
function initializePool(PoolKey calldata poolKey, uint160 sqrtPriceX96, VolatileFeeConfig calldata feeConfig)
        external
        returns (int24 tick);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolKey | `PoolKey` | Pool key; fee must be the dynamic-fee sentinel and hooks must be this contract |
| sqrtPriceX96 | `uint160` | Initial sqrt price |
| feeConfig | `VolatileFeeConfig` | Fee config to seed for the pool |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| tick | `int24` | Resulting tick |

### maxTempFeeBlockGap

Most blocks after the previous block open at which a block's temp fee still applies.

<i>

Past this gap the temp fee is 0 and the permanent fee still steps. Measured in blocks

</i>

```solidity
function maxTempFeeBlockGap() external view returns (uint256);
```

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `uint256` | The max block gap |

### FeeStateUpdated

Emitted on the first swap of each block, when the pool's top-of-block fee state is written

```solidity
event FeeStateUpdated(
        PoolId indexed poolId,
        uint40 blockNumber,
        uint160 sqrtPriceTopX96,
        uint24 askPermFeeE6,
        uint24 bidPermFeeE6,
        uint24 tempFeeE6,
        bool tempOnBid
    );
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolId | `PoolId` | The pool whose state was updated |
| blockNumber | `uint40` | Block the state applies to |
| sqrtPriceTopX96 | `uint160` | Block-open sqrt price |
| askPermFeeE6 | `uint24` | Permanent ask-side fee |
| bidPermFeeE6 | `uint24` | Permanent bid-side fee (restingSpreadE6 - askPermFeeE6) |
| tempFeeE6 | `uint24` | One-block backrun charge on the side named by tempOnBid |
| tempOnBid | `bool` | True if tempFeeE6 is on the bid side, false if on the ask side |
