**Inherits:** [BaseDynamicFeeHook](/src/base/abstract.BaseDynamicFeeHook), [StableFeeConfiguration](/src/stable/base/abstract.StableFeeConfiguration), [IStablePairHook](/src/stable/interfaces/interface.IStablePairHook)

**Title:** StablePairHook

Dynamic fee hook for pools of two assets expected to hold the same price; a UUPS implementation whose ERC1967 proxy
is the registered v4 hook.

<i>

The fee calculations adjust the LP fee to hit the target pre-impact buy/sell prices and do
not take the pool's protocolFee into account if it's turned on.

</i>

**Note:**

- **security-contact:** security@uniswap.org

<a id="getfee-poolkey"></a>

### getFee

The LP fee a swap would be charged this block, per direction.

<i>

StablePair's fee is size-independent (it never reads the swap amount), so this always
returns and never reverts on the size-dependence basis. It reverts only for an uninitialized pool, whose fee is undefined.

</i>

```solidity
function getFee(PoolKey calldata key) external view returns (uint24 feeE6ZeroForOne, uint24 feeE6OneForZero);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| key | `PoolKey` | The PoolKey of the pool |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| feeE6ZeroForOne | `uint24` | The fee for a zeroForOne swap this block |
| feeE6OneForZero | `uint24` | The fee for a oneForZero swap this block |

### _calculateDecayingFee

| ---- | ---- | ----------- |
