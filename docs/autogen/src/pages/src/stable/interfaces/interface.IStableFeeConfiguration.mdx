# IStableFeeConfiguration

[Git Source](https://github.com/Uniswap/v4-hooks-public/blob/3d5b2620fe2b9ba7f01645160e1b841cf585c425/src/stable/interfaces/IStableFeeConfiguration.sol)

Interface for the StableFeeConfiguration

## Functions

<a id="updatefeeconfig-poolid-stablefeeconfig"></a>

### updateFeeConfig

Update the fee config for a pool

```solidity
function updateFeeConfig(PoolId poolId, StableFeeConfig calldata feeConfig) external;
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolId | `PoolId` | The ID of the pool |
| feeConfig | `StableFeeConfig` | The new fee config |

<a id="batchupdatefeeconfig-poolid-stablefeeconfig"></a>

### batchUpdateFeeConfig

Update the fee config for multiple pools in a single call

```solidity
function batchUpdateFeeConfig(PoolId[] calldata poolIds, StableFeeConfig[] calldata feeConfigs) external;
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolIds | `PoolId[]` | The IDs of the pools to update |
| feeConfigs | `StableFeeConfig[]` | The new fee configs for each pool, index-aligned with `poolIds` |
